# Heliosphere Vortex Launch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the single-file app into a tested, fast Vite project ready for public launch before 18 Nov 2026, without losing any feature.

**Architecture:** A browser-free `engine`, plain data modules, then scene, camera and UI modules around a thin `main.js`. The app is moved unchanged first, locked with tests, then split.

**Tech Stack:** Vite, plain ES modules with JSDoc, three@0.128.0, Vitest, Playwright using the installed Chrome.

**Spec:** `docs/specs/2026-11-02-launch-design.md`

## Global Constraints

- three.js stays on r128 (`0.128.0`, exact pin).
- No UI framework, no backend, no accounts, no cookies.
- All scripts, fonts and images are served from the app's own origin.
- Compressed code download under 300 KB.
- First screen on a mid-range phone, 4G, under 2.5 s.
- No NASA logo, and no claim that Voyager has left the galaxy.
- `reference/heliosphere-vortex.original.html` is never edited.
- Pushing, public repo and domain changes wait for the owner's go-ahead.

## Review Focus

- Images missing or slow: the app still opens and shows generated planet surfaces. Test in Task 3.
- WebGL unavailable: a friendly message, not a blank page. Test in Task 6.
- Old shared links (`#solar-system`, `#milky-way`, `#local-group`, `#local-universe`) still open the right level. Test in Task 3.
- Corrupt or old values in saved preferences: the app ignores them and starts. Test in Task 6.
- Clock after the milestone: the countdown switches to time since, and never shows a negative time. Test in Task 6.
